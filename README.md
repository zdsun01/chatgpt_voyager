# ChatGPT Voyager · 提问时间线

<p align="center"><img src="docs/images/icon.png" width="160" height="160" alt="ChatGPT Voyager 图标"></p>

轻量的 Chrome 扩展，在 ChatGPT 网页右侧显示当前聊天的提问时间线。悬停预览自己的提问，点击跳转，滚动阅读时自动高亮对应节点。

当前版本：**1.2.2**。支持 `chatgpt.com` 和 `chat.openai.com`，采用 Manifest V3。

## 功能

- **独立侧边聊天（试用）**：在聊天更多菜单中打开右侧临时聊天，不传入主对话内容；点击 × 销毁页面，再打开从空白开始。
- **提问导航**：只显示自己的提问，不预览模型回答；长问题可在预览框内滚动阅读。
- **点击跳转**：点击圆点定位到对应提问。
- **阅读高亮**：随页面滚动自动切换高亮，阅读某次提问下的回答时保持对应节点选中。
- **返回原文**：使用网页自带的“向 ChatGPT 提问”发送引用追问后，在新回答底部的重试图标后增加 `↩`；悬停提示“返回原文”，点击回到这条回答所引用的段落。
- **返回关系保留**：刷新、重开浏览器或切换聊天后，已记录的返回箭头会在对应回答加载时恢复。
- **历史累积**：向上加载历史时加入新发现的提问，已加载的最新节点不会因为网页卸载消息而消失。
- **聊天隔离**：切换聊天立即清空旧节点，避免混入网页缓存的其他会话。
- **简洁外观**：浅蓝圆点、磨砂玻璃滑轨，支持深色页面。顶部与分享按钮下沿保持 3px 间距，底部留 6px。
- **键盘操作**：Tab 进入节点，方向键切换，Home / End 前往首尾，Enter 跳转，Esc 关闭预览。

## 安装

使用扩展不需要构建，也不需要安装 Node.js。

### 直接下载（推荐）

打开 [最新 Release](https://github.com/zdsun01/chatgpt_voyager/releases/latest)，在 **Assets** 中下载 `chatgpt-question-timeline-版本号.zip`，解压后在 Chrome 扩展管理页选择该文件夹即可，不需要 Git 或 `git pull`。

已发布安装包：[chatgpt-question-timeline-1.2.2.zip](https://github.com/zdsun01/chatgpt_voyager/releases/download/v1.2.2/chatgpt-question-timeline-1.2.2.zip)。选择插件 ZIP，不要选择 GitHub 自动生成的 Source code 源码包。

### 从源码安装

1. 克隆本仓库，或通过仓库页面的 **Code → Download ZIP** 下载并解压源码。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择仓库中的 **extension 文件夹**，该目录下应直接包含 `manifest.json`。
5. 刷新 ChatGPT 页面，进入有提问的聊天即可看到时间线。

如果使用单独打包的扩展 ZIP，解压后选择直接包含 `manifest.json` 的目录。没有提问时，时间线隐藏。

### 更新

用新版文件覆盖原来的扩展目录；使用 Git 克隆安装的，也可以在仓库目录执行 `git pull`。随后在 `chrome://extensions` 中点击本扩展的**重新加载**，再刷新 ChatGPT 页面。更新后，版本应显示 **1.2.2**。请复制新版全部文件，包括 `return-origin.js`、`return-storage.js`、新增的 `side-chat.js` 和 `icons/` 图标目录。返回关系保存使用 `storage` 权限，用于在浏览器本地保存返回关系。

## 使用说明

普通圆点为 12px 浅蓝色。悬停或键盘聚焦时放大至 14px，并显示蓝色外圈；当前阅读节点使用蓝色填充和浅蓝光圈。界面不显示提问序号或操作说明，预览只包含提问正文。

高亮以聊天可视区域中线为参考：提问经过中线后，对应节点保持高亮，直到下一次提问经过中线；滚到底部时高亮最新节点。节点很多时，时间线自动滚动以显示当前节点，也可在滑轨上使用滚轮查看其他节点。

向上翻阅时，逐步累积当前聊天已经加载过的提问。切换浏览器标签页后保留这些记录；切换聊天或刷新网页后重新积累。

### 独立侧边聊天（试用）

1. 在已有聊天右上角的 **⋯ → 新建侧边聊天** 打开面板，也可按 **Ctrl + Alt + S**。
2. 右侧加载登录账号的 ChatGPT 原生临时聊天，使用原生输入框和模型选择器。侧边页隐藏“显示/隐藏侧边栏”和“新建聊天”入口，保留面板顶部的关闭按钮。插件不复制主聊天的文字、项目文件或引用。
3. 拖动中间分隔线调整宽度；窄屏时面板覆盖页面。主时间线随主聊天可用宽度调整。
4. 点击右上角 **×** 关闭并销毁整个侧边页面。再次打开为新的空白临时聊天，刷新主页面也会关闭侧边聊天。

本版借助原生临时聊天实现“不留下历史条目”：会话本来就不加入历史列表，不需要在关闭时删除普通聊天，也不会操作主聊天的删除按钮。只有识别到原生临时模式时才显示输入界面；模式识别失败或退出时暂停使用并提示重新加载。侧边页禁止跳入已有聊天或保存为普通历史聊天。账户的个性化设置仍由 ChatGPT 控制，不传主对话不等于关闭账户记忆。

关闭会释放扩展持有的页面、监听器和观察器；未打开时不预加载。打开期间需要运行另一份 ChatGPT 网页，内存开销会高于单独时间线，尚未测量真实页面进程占用。原生临时聊天不出现在历史中不等于关闭后立即清除服务端副本，具体遵循 [OpenAI 临时聊天说明](https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt)。

已在独立的官方临时聊天中验证发送与回复，并适配发送后顶部变成“保存聊天”的状态。用户提供的截图确认侧边面板内已能显示官方临时聊天和个性化菜单；完整内嵌发送、关闭和重新打开流程仍未完成实网页端到端验证，侧边聊天继续标记为试用。若面板提示无法加载，可重新加载并记录提示以便排查。

### 追问后返回原文

1. 选中模型回答中不理解的文字，点击 ChatGPT 自带的“向 ChatGPT 提问”（英文界面为 “Ask ChatGPT”）。
2. 在原生输入框中输入并发送追问，等待对应回答的底部操作栏出现。
3. 在该回答的**重试图标后、更多图标前**找到 `↩`，悬停显示“返回原文”。点击回到这次追问引用的段落，并短暂高亮原文字。

每条引用追问的回答只保留一个箭头，独立绑定自己的来源。例如从 A 引用追问得到 B 和 C，则 B→A、C→A；再从 B 引用追问得到 D，则 D→B，B→A 不变。箭头可重复点击。连续追问时，可以使用各条回答旁的箭头逐层返回。每个聊天最多保留最近 20 条关联，按聊天 ID 分开保存到扩展本地存储。刷新、关闭后重新打开、切换聊天再回来，都会在对应回答加载时恢复箭头。最多保存最近有新增或更新返回关系的 50 个聊天，总保存数据不超过 512 KiB；达到上限时淘汰最旧聊天的记录。仅选中文字、复制文字，或者发送前取消引用，不会创建箭头。插件不添加 Ask ChatGPT 按钮，也没有悬浮返回面板。

如果长对话中的原文已被网页临时卸载，会先滚动尝试加载，再根据消息标识和文字定位。找到后会短暂检查位置是否稳定，校正补载内容、公式重排或网页自动滚动造成的偏移。整个定位过程最多 5 秒，手动滚动可立即中止；暂时找不到时保留返回点，可加载原文后重试。普通手动输入的追问不会自动创建返回点。

如果插件没有保存对应返回关系，但提问仍带有网页原生的“1 个已选文本片段”按钮，会恢复一个 ↩ 入口，点击调用这条提问自己的原生引用定位。它与点击原生引用按钮的效果一致，不保证恢复插件额外保存的段落高亮。没有本地记录也没有可用原生引用入口时，无法补建来源。极少数没有稳定消息标识的消息仍只在本次页面内支持返回。卸载扩展会清除保存的数据，更新时请覆盖原目录并重新加载，避免卸载重装。

## 常见问题

**安装或更新后没有时间线？**

确认加载的是包含 `manifest.json` 的 `extension` 目录，扩展已启用且允许访问当前站点，然后重新加载扩展并刷新 ChatGPT 网页。空聊天不显示时间线。

**为什么很早的提问还没有节点？**

先向上滚动，让 ChatGPT 加载相应历史消息。插件发现后会将这些节点加入时间线。

**为什么长对话的滑轨可以滚动？**

节点多时保留最小点击间距，并通过虚拟列表显示可见部分。可使用滑轨滚轮或键盘查看其他节点。

  side-chat.js                  独立临时侧边聊天、模式检查与关闭清理
tests/
  timeline.test.cjs              基础交互与大量节点测试
  chat-switch.test.cjs           聊天切换与缓存页面隔离测试

  scroll-active.test.cjs         滚动高亮与监听生命周期测试
  return-origin.test.cjs         划词回跳、连续追问、重挂载与聊天隔离测试
  return-branching.test.cjs      分支追问、历史重挂载与单一返回箭头测试
  return-storage.test.cjs        存储容量、多标签页合并与后台重启测试
  return-persistence.test.cjs    刷新恢复、聊天隔离、延迟加载与失败降级测试
  return-settling.test.cjs       首次回跳后的延迟布局、滚动复位与中断测试
  return-native.test.cjs         历史原生引用备用入口与精确记录恢复去重测试

CHANGELOG.md                    更新记录

## 开发与验证

本机需安装支持当前 Playwright 的 Node.js 版本和 Google Chrome。测试通过 Playwright 启动本机 Chrome，使用拦截的模拟网页，不需要登录 ChatGPT。

```sh
npm ci
npm test
```

测试覆盖新旧页面结构、预览与跳转、动态增删、聊天隔离、历史累积、滚动高亮、后台恢复、纯文本渲染，以及 2,000 条提问时有限的按钮渲染数量。也检查模型流式输出和单纯滚动不会触发提问列表重扫。

1.1.0 的完整回跳流程已由用户在真实 ChatGPT 页面实测通过。

Playwright 仅用于开发，不随扩展运行。`node_modules/`、`test-results/` 和 ZIP 包不纳入源码版本控制。

### 打包

在仓库根目录使用 PowerShell：

```powershell
Compress-Archive -Path extension/* -DestinationPath chatgpt-question-timeline.zip -Force
```

包内包含 `manifest.json`、`content.js`、`return-origin.js`、`return-storage.js`、`side-chat.js` 和 `icons/` 图标目录，不包含测试或开发依赖。
